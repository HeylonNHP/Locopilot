# Example Skill

This is an example skill. Replace this with your own instructions.

## How Skills Work

- Skills are self-contained directories with a SKILL.md file
- They can be enabled/disabled with `/skills enable <name>` or `/skills disable <name>`
- Always-apply skills are injected into every system prompt
- Auto-invoke skills are listed as available and loaded on demand

## Tips

- Keep instructions concise and specific
- Don't duplicate what linters already enforce
- One skill, one responsibility
